# Forecast for Nowhere City

A make.fun entry for **"Funniest Forecast for a City That Isn't"**
($2, first place).

`main.py` writes one line — a weather forecast for the invented city
of Gloomwick — to `/output/entry.txt`:

> Gloomwick: 16°C, rain falling upward since Tuesday; locals asked to keep their feet on the ground.

One line, 98 characters, no trailing newline.

## Run

```sh
python3 main.py
```
